# Code QTE

Расширение для Visual Studio Code: случайные Quick Time Events во время работы с кодом. Успешная реакция приносит очки, ошибка или истечение времени сбрасывает текущий счет. Рекорд сохраняется.

## Разработка

Проект не требует сторонних npm-пакетов. Откройте папку в VS Code и нажмите **F5**, чтобы запустить отдельное окно Extension Development Host. Проверки: `npm test` и `npm run check`.

## План

- Три вида заданий на реакцию.
- Сохранение очков и статистики.
- Отмена заданий при потере фокуса без штрафа.
- Учет времени вне фокуса.
- Установочный VSIX и отчет по лабораторной работе.
