# Code QTE

Quick Time Events для **Visual Studio Code**. Пока вы пишете код, через случайные интервалы рядом с редактором появляется задание на реакцию. Выполняйте его, набирайте очки и улучшайте рекорд.

## Установка и быстрый запуск

1. Возьмите `code-qte-1.0.0.vsix` из папки проекта. Для повторной сборки установите Node.js 22 или новее и выполните `npm run package`.
2. В VS Code откройте панель расширений (`Ctrl+Shift+X`), нажмите **… → Install from VSIX…** и выберите файл.
3. Откройте палитру команд (`Ctrl+Shift+P`) и выполните **Code QTE: Задание сейчас**, чтобы попробовать игру сразу.

После запуска редактора расширение активируется автоматически. По умолчанию задания включены и появляются каждые **45–120 секунд**, на ответ дается **5 секунд**. Для ответа панель задания получает фокус; после ее закрытия можно продолжить писать код. Исходный код и файлы пользователя расширение не изменяет.

## Задания и очки

| Задание | Что делать | Базовые очки |
| --- | --- | ---: |
| Быстрое нажатие | Нажать показанную клавишу | 10 |
| Кодовая комбинация | Ввести четыре показанные клавиши по порядку | 25 |
| Поймайте момент | Нажать пробел, когда маркер находится в зеленой зоне | 20 |

К базовым очкам прибавляется бонус за скорость: `ceil(10 × доля оставшегося времени)`, от 0 до 10 очков. Маркер проходит дорожку за 1,8 секунды и повторяет движение до конца задания.

Неверное нажатие, истечение времени, `Esc` или закрытие уже начатой панели **сбрасывают текущий счет до нуля** и увеличивают счетчик ошибок. Рекорд остается. После результата панель закрывается через 1,6 секунды.

Используются физические позиции клавиш A, S, D, F, J, K, L (`KeyboardEvent.code`): английская и русская раскладки работают одинаково. Удерживание клавиши не засчитывается как повторное нажатие. Сочетания с Ctrl, Alt и Meta игнорируются, чтобы сохранить команды редактора. Ответ принимается внутри панели задания.

## Фокус окна и сохранение

- Пока окно VS Code не в фокусе, новые задания не появляются.
- Если фокус потерян во время задания, оно отменяется **без штрафа**. Возвращение в редактор запускает новый случайный интервал.
- Пауза и изменение настроек также отменяют текущее задание без штрафа.
- Время вне фокуса накапливается, даже если задания поставлены на паузу. Оно видно в строке состояния и статистике.
- Очки, рекорд, успехи, ошибки и время хранятся локально через `globalState`. Сохранение происходит после результата, при смене фокуса, каждые 15 секунд и при штатном завершении. При аварийном закрытии могут потеряться последние 15 секунд учета.
- Время, когда VS Code закрыт, не учитывается. Учет начинается с активации расширения и относится к текущему окну. Общая статистика нескольких одновременно открытых окон не объединяется; рекомендуется играть в одном окне одного профиля.

Расширение не читает код, не обращается к сети и не отправляет статистику на сервер. Задания работают в обычной Webview-панели: VS Code API не предоставляет произвольные плавающие элементы поверх редактора.

## Команды

Все команды доступны в палитре (`Ctrl+Shift+P`). Нажатие на **QTE** в строке состояния открывает статистику.

| Команда | Назначение |
| --- | --- |
| Code QTE: Включить / приостановить | Включить или поставить задания на паузу |
| Code QTE: Задание сейчас | Открыть случайное задание без ожидания интервала |
| Code QTE: Статистика | Показать очки, рекорд, результаты и время вне фокуса |
| Code QTE: Сбросить статистику | Обнулить все показатели после подтверждения |

## Настройки

Откройте настройки и найдите **Code QTE** или добавьте в `settings.json`:

```json
{
  "codeQte.enabled": true,
  "codeQte.minIntervalSeconds": 45,
  "codeQte.maxIntervalSeconds": 120,
  "codeQte.reactionSeconds": 5
}
```

Интервалы задаются в пределах 5–3600 секунд, время реакции — 2–30 секунд. Если максимальный интервал меньше минимального, используется минимальный. Настройки применяются сразу и заново запускают ожидание. Команда паузы учитывает, задано ли включение на уровне рабочей области.

## Разработка и проверки

Требуются **VS Code 1.85+** и **Node.js 22+** для тестов и упаковки. Сторонних npm-зависимостей нет, `npm install` не требуется.

1. Откройте папку проекта в VS Code.
2. Нажмите **F5** и выберите **Запустить Code QTE**.
3. В новом окне Extension Development Host запустите команду задания.

```sh
npm test
npm run check
npm run package
```

`npm test` запускает 17 тестов: игровая логика и адаптер VS Code с имитацией API, включая границы тайм-аута, фокус, устаревшие сообщения и сохранение. `npm run check` проверяет синтаксис. `npm run package` создает VSIX стандартного формата ZIP с манифестом, без установки дополнительных инструментов.

Дополнительно выполнена проверка в реальном VS Code 1.144.0: установка VSIX в отдельный профиль, активация, регистрация команд, открытие панели и пауза. Повторить проверку активации можно через `--extensionDevelopmentPath=<папка проекта> --extensionTestsPath=<папка проекта>/scripts/vscode-smoke.js`, указав отдельные `--user-data-dir` и `--extensions-dir`. Результат записывается в `.work/vscode-smoke.json`.

## Структура

```text
src/game.js                Игровая логика, очки, расписание и учет времени
src/extension.js           Команды, Webview, фокус и сохранение
media/event.js             Клавиатурный ввод и отображение задания
media/event.css            Оформление с поддержкой темы VS Code
test/                     Автоматические проверки
scripts/package.js        Сборка установочного VSIX
scripts/vscode-smoke.js    Проверка активации в настоящем VS Code
```
